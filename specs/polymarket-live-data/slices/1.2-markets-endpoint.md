# Slice 1.2 — `GET /api/v1/games/markets` endpoint

## Objective

Expose Slice 1.1's tag-parameterized `PolymarketService.get_nba_markets()`
over HTTP as a new route, independent of today's NBA schedule or
game-matching (`match_to_game`) — so it returns real market data even when
`NBADataService.get_todays_games()` is empty, which it will be for NBA
during the offseason. This is the endpoint the frontend (Slice 1.3) calls.

## User story

As the developer, I can `curl` (or have the frontend fetch)
`GET /api/v1/games/markets?tag_slug=wnba` and get back real, live Polymarket
market data over HTTP — proving the pipeline works end-to-end from Gamma API
through the service layer through the API layer, not just inside a Python
REPL.

## Context

**File:** `backend/routers/games.py`

The existing `/today/markets` route (line ~86) is a **different, more
complex** shape — it pairs each of today's NBA games with a matched
Polymarket market via `match_to_game`, and returns `[]` when there are no
games. The new `/markets` route is deliberately simpler: it returns
Polymarket markets directly, with no game-matching and no dependency on the
schedule. Do not extend `/today/markets` — add a new route.

**AFTER (tomorrow) — new route added after `/today/markets`:**
```python
from typing import List
...

@router.get(
    "/markets",
    response_model=List[PolymarketMarket],
    status_code=status.HTTP_200_OK,
    summary="Raw Polymarket markets for a sport/tag",
    description=(
        "Return live Polymarket market data for the given tag_slug, "
        "independent of today's scheduled games. Defaults to NBA; pass "
        "tag_slug=wnba to reach live data during the NBA offseason."
    ),
)
async def markets(
    tag_slug: str = "nba",
    poly: PolymarketService = Depends(_get_poly_service),
) -> List[PolymarketMarket]:
    """Raw Polymarket markets for tag_slug, no game-matching."""
    raw = poly.get_nba_markets(tag_slug=tag_slug)
    return [PolymarketMarket(**m) for m in raw]
```

**Why a bare list, not a wrapped response object:** the PRD test
(`run-prd-test.sh`) parses the response body directly as a JSON array
(`isinstance(data, list)`) and checks fields like `market_id`, `question`,
`price_a`, `best_bid` on each element — it does not expect a
`{"markets": [...], "count": ..., "generated_at": ...}` envelope like
`TodayMarketsResponse`/`NBAMarketsResponse` use elsewhere in this file.
`response_model=List[PolymarketMarket]` matches the PRD test's contract
exactly; don't wrap it to match the envelope convention used by sibling
routes.

**DO ✅ — query param with a default, reusing the existing schema:**
```python
async def markets(
    tag_slug: str = "nba",
    poly: PolymarketService = Depends(_get_poly_service),
) -> List[PolymarketMarket]:
    raw = poly.get_nba_markets(tag_slug=tag_slug)
    return [PolymarketMarket(**m) for m in raw]
```

**DON'T ❌ — require a matching scheduled game (breaks the "independent of
schedule" requirement):**
```python
async def markets(tag_slug: str = "nba", ...):
    games = nba.get_todays_games()
    if not games:
        return []   # wrong — PRD requires data even when schedule is empty
    ...
```

## Forward-Looking Requirements

### For Slice 1.3 (frontend)
- Endpoint path: `GET /api/v1/games/markets?tag_slug=wnba` (full path
  including the `/api/v1` prefix mounted in `main.py`).
- Response is a **bare JSON array** of objects each shaped like
  `PolymarketMarket` (`market_id`, `question`, `outcome_a`, `outcome_b`,
  `price_a`, `price_b`, `best_bid`, `best_ask`, `last_trade_price`,
  `volume`, `liquidity`, `close_time`, `active`, `closed`) — no wrapper
  object, no pagination.
- Frontend should call with `tag_slug=wnba` to get live data (NBA will be
  empty/stale during offseason, same reasoning as Slice 1.1).

## Success Criteria

- `GET /api/v1/games/markets` (default `tag_slug=nba`) returns HTTP 200 with
  a JSON array (possibly containing only resolved/stale markets, or empty,
  during NBA offseason — that's expected and acceptable for the default).
- `GET /api/v1/games/markets?tag_slug=wnba` returns HTTP 200 with a
  non-empty JSON array, and at least one element has a genuine bid/ask
  spread (`0.01 < best_ask - best_bid < 0.99`) and a non-empty `question`.
- The endpoint's response is unaffected by `NBADataService.get_todays_games()`
  being empty — no dependency on the schedule or `match_to_game`.
- `SecurityHeadersMiddleware` and the rate limiter apply automatically
  (inherited from `app.add_middleware` / `app.state.limiter` in
  `main.py` — no route-level bypass).
- `/today/markets` and all other existing routes in `games.py` are
  unchanged.
