# Slice 1.1 — Parameterize `PolymarketService.get_nba_markets`

## Objective

`get_nba_markets()` currently hardcodes `tag_slug="nba"` when calling
Gamma's `/events` endpoint (`backend/services/polymarket.py:96`). During the
NBA offseason this only ever returns stale/resolved markets. Add a
`tag_slug` parameter so a caller can request a different sport's markets —
mirroring the pattern `OddsService.get_nba_game_lines(sport=...)` already
uses in `backend/services/odds.py` — without touching the service's
internals (parsing, filtering, caching mechanism).

## User story

As a caller of `PolymarketService` (the edge engine today, the new endpoint
in Slice 1.2 tomorrow), I can pass `tag_slug="wnba"` and get back real,
currently-live WNBA markets instead of NBA's offseason-stale ones, so I can
prove the Gamma API integration actually works end-to-end.

## Context

**File:** `backend/services/polymarket.py`

**BEFORE (today):**
```python
_TTL_MARKETS  = 15 * 60   # 15 min — prices move faster than odds

class PolymarketService:
    def get_nba_markets(self) -> List[Dict]:
        key = "poly_nba_markets"
        cached = self._cache.get(key)
        if cached is not None:
            return cached

        logger.info("API CALL  get_nba_markets  source=Gamma")
        markets = self._fetch_gamma_markets(tag_slug="nba", limit=200)

        structured = [self._parse_market(m) for m in markets if self._is_relevant(m)]
        logger.info("Polymarket: %d structured NBA markets returned", len(structured))
        self._cache.set(key, structured, _TTL_MARKETS)
        return structured
```

**AFTER (tomorrow):**
```python
_TAG_NBA      = "nba"
_TAG_WNBA     = "wnba"   # used as live stand-in for NBA markets during the offseason
_TTL_MARKETS  = 15 * 60   # 15 min — prices move faster than odds

class PolymarketService:
    def get_nba_markets(self, tag_slug: str = _TAG_NBA) -> List[Dict]:
        key = f"poly_markets:{tag_slug}"
        cached = self._cache.get(key)
        if cached is not None:
            return cached

        logger.info("API CALL  get_nba_markets  source=Gamma  tag_slug=%s", tag_slug)
        markets = self._fetch_gamma_markets(tag_slug=tag_slug, limit=200)

        structured = [self._parse_market(m) for m in markets if self._is_relevant(m)]
        logger.info("Polymarket: %d structured markets returned (tag_slug=%s)", len(structured), tag_slug)
        self._cache.set(key, structured, _TTL_MARKETS)
        return structured
```

Note the cache key changes from the flat string `"poly_nba_markets"` to a
tag-aware `f"poly_markets:{tag_slug}"`. This is required, not cosmetic —
`odds.py`'s cache key is already sport-aware (`f"odds_lines:{sport}"`,
odds.py:451); without this, a call with `tag_slug="wnba"` would read/write
the same cache entry as `tag_slug="nba"` and the two would silently collide,
which is exactly the bug the PRD test's identity check
(`nba_ids == wnba_ids`) is designed to catch.

The method's docstring, `_fetch_gamma_markets`, `_is_relevant`,
`_parse_market`, `match_to_game`, and `get_market_probability` are unchanged
— only the tag threaded through the one entry point.

**DO ✅ — default-valued parameter, mirrors `odds.py`:**
```python
def get_nba_markets(self, tag_slug: str = _TAG_NBA) -> List[Dict]:
```

**DON'T ❌ — a sport-config abstraction (out of scope per PRD constraints):**
```python
SPORT_CONFIG = {"nba": {...}, "wnba": {...}}  # no — PRD says mirror odds.py's
                                                # simple default-valued param,
                                                # don't introduce new config machinery
```

## Forward-Looking Requirements

### For Slice 1.2 (endpoint)
- The route will call `poly.get_nba_markets(tag_slug=<query param>)` and
  needs the method signature finalized here first.
- The endpoint's default `tag_slug` should be `"nba"` (matches existing
  default behavior elsewhere in the router) — the caller supplies `"wnba"`
  explicitly to reach live data, consistent with the PRD's "capability, not
  automatic fallback" framing.

## Success Criteria

- `PolymarketService.get_nba_markets(tag_slug="wnba")` and
  `PolymarketService.get_nba_markets(tag_slug="nba")` (or no argument) both
  succeed and return **different** sets of `market_id`s.
- `get_nba_markets(tag_slug="wnba")` returns at least one market with
  `0.01 < best_ask - best_bid < 0.99` (a genuine open spread, not a
  resolved-to-0/1 market).
- Existing callers of `get_nba_markets()` with no arguments (e.g.
  `routers/games.py`'s `/today/markets`, `edge_engine.py` if it calls this
  service) continue to work unchanged — default parameter preserves
  backward compatibility.
- `match_to_game`, `get_market_probability`, `_is_relevant`, `_parse_market`
  are untouched.
