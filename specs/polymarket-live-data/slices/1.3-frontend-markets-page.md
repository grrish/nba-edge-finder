# Slice 1.3 — Frontend markets page (final slice)

## Objective

Add a frontend page that fetches `GET /api/v1/games/markets?tag_slug=wnba`
(Slice 1.2) and renders each returned market's `question` and price, so the
developer has visual proof the data pipeline works end-to-end — not just
that the backend returns JSON. This is the **final slice** of the feature:
its Success Criteria requires running the PRD's test runner,
`./prds/polymarket-live-data/run-prd-test.sh`, and it must exit 0. That
script is the feature's actual definition of done — treat every check
inside it (backend service, HTTP endpoint, and this frontend page) as
binding, not just the frontend portion.

## User story

As the developer, I can open the app and see a page listing real, live
WNBA Polymarket markets with their questions and prices, so I have visual
(not just programmatic) confirmation the integration is real.

**New file:** `frontend/src/pages/Markets.jsx` — mirrors `Games.jsx`
structure:
```jsx
import { useEffect, useState } from "react";
import client from "../api/client";

export default function Markets() {
  const [markets, setMarkets] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    client
      .get("/api/v1/games/markets", { params: { tag_slug: "wnba" } })
      .then((r) => setMarkets(r.data ?? []))
      .catch((e) => setError(e.message))
      .finally(() => setLoading(false));
  }, []);

  return (
    <main className="p-8">
      <h1 className="text-3xl font-bold mb-6">Polymarket Markets</h1>
      {loading && <p className="text-slate-400 animate-pulse">Loading…</p>}
      {error && <p className="text-edge-negative">{error}</p>}
      {!loading && !error && markets.length === 0 && (
        <p className="text-slate-400">No live markets found right now.</p>
      )}
      <div className="space-y-3">
        {markets.map((m) => (
          <div
            key={m.market_id}
            className="bg-slate-800 rounded-2xl p-5 border border-slate-700 flex items-center justify-between"
          >
            <p className="font-semibold">{m.question}</p>
            <div className="text-right">
              <p className="text-xl font-bold text-brand-500">
                {(m.price_a * 100).toFixed(0)}%
              </p>
              <p className="text-slate-400 text-xs">{m.outcome_a}</p>
            </div>
          </div>
        ))}
      </div>
    </main>
  );
}
```

Note the response is a **bare array** (Slice 1.2's `List[PolymarketMarket]`),
so `r.data` is the array directly — unlike `Games.jsx`/`Props.jsx` which
unwrap `r.data.edges`.

**`App.jsx` — add the route:**
```jsx
import Markets from "./pages/Markets";
...
<Route path="/markets" element={<Markets />} />
```

**`Navbar.jsx` — add to the `links` array:**
```jsx
const links = [
  { to: "/", label: "Dashboard" },
  { to: "/games", label: "Games" },
  { to: "/props", label: "Props" },
  { to: "/markets", label: "Markets" },
];
```

**DO ✅ — read the bare-array response directly:**
```jsx
.then((r) => setMarkets(r.data ?? []))
```

**DON'T ❌ — assume a wrapped envelope like the other pages use:**
```jsx
.then((r) => setMarkets(r.data.markets ?? []))  // wrong — /games/markets
                                                  // returns a bare array,
                                                  // not { markets: [...] }
```

## Success Criteria

- `frontend/src/pages/Markets.jsx` exists, imports the shared `client`, and
  fetches `/api/v1/games/markets` (grep-visible as `games/markets`).
- The component reads `.question` and at least one of `price_a`/`price_b`
  from each returned market and renders them.
- `App.jsx` routes `/markets` to the new page; `Navbar.jsx` links to it.
- `cd frontend && npm run build` succeeds with no errors.
- No new frontend dependencies added (PRD constraint — reuse `axios` via
  the existing `client`).
- **Definition of done for the whole feature:** run
  `./prds/polymarket-live-data/run-prd-test.sh` from the repo root. It must
  exit 0. It independently verifies: `PolymarketService.get_nba_markets`
  accepts `tag_slug` and returns genuinely different, live data for `"wnba"`
  vs `"nba"` (Slice 1.1); `GET /api/v1/games/markets?tag_slug=wnba` is
  reachable over HTTP and returns live market data (Slice 1.2); and this
  page's source references the endpoint and reads `question` + a price
  field, plus a successful `npm run build`. Do not report this slice or the
  feature complete until the runner exits 0 — its internals (a live network
  call to Polymarket's Gamma API plus a real server boot) are the actual
  contract, not a proxy for it.
